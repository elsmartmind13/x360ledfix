# X360 LED Fix

Маленькое приложение для Google TV / Android TV, которое **гасит мигание всех четырёх
индикаторов геймпада Xbox 360** ( wireless-контроллер через фирменный
«Xbox 360 Wireless Gaming Receiver for Windows»).

## Почему мигают все четыре индикатора

Индикаторы вокруг кнопки Guide (Ring of Light) назначает **хост**: после сопряжения
по радиоканалу он должен отправить геймпаду команду *Set LED* («зажги квадрант №N»).
Windows это делает автоматически — поэтому на ПК всё правильно.

Прошивка Google TV (в т. ч. на TCL 3T6D-RU) воспринимает ресивер как обычное
USB-устройство ввода: радиоканал поднимается, кнопки работают, но команду Set LED
никто не отправляет. Геймпад остаётся в состоянии «подключён, игрок не назначен» —
это и есть постоянное мигание всех четырёх квадрантов. Это штатное поведение
контроллера, а не поломка.

## Что делает приложение

Один раз (или по расписанию) отправляет геймпаду тот же пакет, что и драйвер xpad
ядра Linux, — 12-байтовую LED-команду:

```
01 00 08 (0x40 + код) 00 00 00 00 00 00 00 00
```

Коды: `0` — погасить, `1` — мигать всеми, `6..9` — постоянно горящий квадрант
«Игрок 1..4», `10` — бегущий огонёк.

Пакет отправляется в OUT-endpoint каждого из четырёх интерфейсов ресивера (по одному
на потенциального игрока), поэтому сработает для любого сопряжённого геймпада.

Как только приложение занимает USB-интерфейс принудительно (он мог быть занят
ядерным драйвером телевизора), оно **возвращает драйвер системе** после отправки
команды — кнопки геймпада продолжают работать. Если интерфейс занят не ядерным
драйвером, а сервисным процессом системы, приложение честно сообщит «занята»:
в этом случае вытащите ресивер и вставьте обратно, затем нажмите кнопку сразу.

## Сборка APK

### Вариант А — через GitHub Actions (ничего не нужно устанавливать)

1. Создайте репозиторий на GitHub (например, `x360ledfix`).
2. Распакуйте этот проект и загрузите все файлы в репозиторий.
3. Откройте вкладку **Actions** → workflow **Build APK** → **Run workflow**.
4. Через 3–5 минут в результате запуска появится артефакт
   `x360ledfix-debug-apk` со готовым `app-debug.apk`.

### Вариант Б — Android Studio

Откройте папку проекта в Android Studio → Build → Build Bundle(s)/APK(s) →
Build APK(s). Сначала студия установит Gradle и NDK сама.

## Установка на TCL (Google TV)

1. Скопируйте `app-debug.apk` на USB-флешку или скачайте его на телевизор.
2. Настройки → Приложения → Разрешения безопасности → Неизвестные источники →
   разрешите установку вашему файловому менеджеру.
3. Установите APK.

Либо через ADB (ПК и ТВ в одной сети):

```
adb connect <IP-телевизора>:5555
adb install app-debug.apk
```

## Как пользоваться

1. Вставьте ресивер в USB-порт телевизора, включите геймпад.
2. Откройте приложение. Подтвердите диалог доступа к USB-устройству
   (можно поставить галочку «всегда»).
3. Нажмите **«Погасить индикаторы»** или **«Игрок 1»** — мигание прекратится.
4. Включите галочку **«Повторять каждые 10 секунд»**, чтобы после
   отключения/включения геймпада команда ставилась заново (пока приложение
   открыто).
5. Кнопки геймпада при этом продолжают работать в играх как раньше.

## Технические детали

- Ресивер не является USB-HID-устройством: это 4 vendor-class-интерфейса
  (по одному на игрока), в каждом — interrupt IN и interrupt OUT endpoint.
- Формат пакетов и коды LED взяты из драйвера `xpad` ядра Linux
  (`xpad_send_led_command`, XTYPE_XBOX360W).
- Интерфейс захватывается через `UsbDeviceConnection.claimInterface(force=true)`
  (в ядре — ioctl `USBDEVFS_DISCONNECT_CLAIM`) и освобождается сразу после
  отправки; при необходимости возвращается драйверу через ioctl
  `USBDEVFS_CONNECT`.
- LED-состояние хранится в самом геймпаде, поэтому достаточно одной команды
  до его отключения/переподключения.
